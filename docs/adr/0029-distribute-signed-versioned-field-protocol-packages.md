# Distribute signed versioned field protocol packages

The executable field playbook will be a signed, integrity-checked Field Protocol Package built from
repository-reviewed source rather than runtime Markdown, a production authoring UI, or divergent
handwritten validators. Each package pins compatible Campaigns, Assignments, schemas, registries,
methods, governed Subjects, geography, branching rules, and help text; canonical machine-readable
schemas generate application bindings. Active work remains pinned, and breaking updates require an
explicit Protocol Migration that preserves originals and quarantines ambiguity.
