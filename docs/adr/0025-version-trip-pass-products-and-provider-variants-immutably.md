# Version Trip Pass Products and provider Variants immutably

Every launched Lemon Squeezy Variant maps to one immutable local Trip Pass Product version. Changing
price, currency, duration, allowance, tax presentation, or other commercial meaning creates a new
Product version and Variant while historical Orders retain their original references. Lemon Squeezy
license keys remain disabled because verified Payment Facts and Ask Siargao's Trip Pass ledger own
access.
